# SignalDig Skill

This directory publishes one primary Skill: `research-growth-signals`.

It operates one SignalDig MCP connection with two business tools: `research_social_signals` and `research_seo_signals`.

The historical `research-social-signals`, `research-seo-signals`, and `decide-content-opportunities` directories remain installable compatibility entries for one release cycle. They delegate to the primary Skill and do not maintain separate request parameters.
