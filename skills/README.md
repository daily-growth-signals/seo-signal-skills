# SignalDig Skill

This directory publishes one primary Skill: `research-growth-signals`.

It operates one SignalDig MCP connection with two business tools: `research_social_signals` and `research_seo_signals`.

The historical directories remain in the repository only for one final ClawHub and SkillHub compatibility sync. They are no longer included in downloadable release packages, and later hub releases publish only the primary Skill unless a compatibility entry is deliberately changed.
