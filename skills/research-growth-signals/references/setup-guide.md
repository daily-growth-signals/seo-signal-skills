# SignalDig Connection Setup

Configure one Streamable HTTP MCP connection using the SignalDig endpoint and Bearer API key shown on [Connect SignalDig](https://signaldig.com/agent-setup).

**Example server alias (configurable):** `signaldig`

After connecting, the visible tool inventory must include:

- `research_social_signals`
- `research_seo_signals`

The alias is client-defined and has no effect on the Skill. Installing this Skill alone does not connect the MCP service.
