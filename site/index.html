Developer Installation

Clone the repo and create symbolic links to your agent's skills directory. Each skill includes its own instructions, agent metadata, and only the references or templates it needs.

Step 1: Clone the repository

git clone https://github.com/daily-growth-signals/seo-signal-skills.git

Step 2: Choose your agent & create symlinks

Select an agent platform to see the exact commands for each skill.

Step 3: Connect MCP servers (optional naming)

Note: The server names below (e.g., daily-growth-signals) are reference names. You can customize them when configuring your AI client. The actual service endpoints remain the same.

Simple Download Installation

Download the pre-packaged skills zip file and extract it to your agent's skills directory. No Git or command line experience required.

Step 1: Download the latest release

Download seo-signal-skills.zip ↓

Contains all three skill folders ready to use

Step 2: Extract the zip file

1

Locate the downloaded seo-signal-skills-*.zip file

2

Right-click and choose "Extract All" (Windows) or double-click (Mac)

3

You'll see three folders: research-seo-signals, research-social-signals, decide-content-opportunities

Step 3: Copy folders to your agent

Find your agent's skills folder and copy all three skill folders there:
