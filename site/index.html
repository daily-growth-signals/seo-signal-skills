How a research request runs

The same tool submits the request and reads the result. A single analysis ID keeps the run traceable.

01

Submit research

action: submit

The Skill selects Social or SEO, sends the smallest useful scope, and stores the returned analysis ID.

→
02

Poll the result

action: get

It checks that same analysis ID until the run completes. Slow work is not submitted twice.

→
03

Read the evidence

The answer includes the actual coverage, source links, gaps, and analysis ID. Missing data stays unknown rather than becoming a guessed value.

Developer Installation

Clone the repository and copy research-growth-signals into your agent's skills directory. Commands are provided for macOS/Linux and Windows.

Step 1: Clone the repository

Same clone command on every OS. On Windows, run it in Git Bash, PowerShell (with Git installed), or Windows Terminal.

git clone https://github.com/daily-growth-signals/seo-signal-skills.git

Step 2: Choose your OS, agent, and copy the Skill

Pick your operating system first, then the AI client. Run the copy command from the parent folder of seo-signal-skills (the directory that contains the cloned repo).

macOS / Linux: run the command in Terminal from the parent of the cloned repo.

Step 3: Connect SignalDig MCP

Note: The alias signaldig is configurable. Every client connects to the same endpoint.

Tip: Register the SignalDig MCP server once per agent — connection parameters are fixed. Examples for common clients:

Claude Code

.mcp.json (project root)

{
  "mcpServers": {
    "signaldig": {
      "type": "http",
      "url": "https://mcp.signaldig.com/mcp",
      "headers": {
        "Authorization": "Bearer ${SIGNALDIG_API_KEY}"
      }
    }
  }
}

Codex

macOS/Linux: ~/.codex/config.toml · Windows: %USERPROFILE%\.codex\config.toml

[mcp_servers.signaldig]
url = "https://mcp.signaldig.com/mcp"
bearer_token_env_var = "SIGNALDIG_API_KEY"
enabled = true
default_tools_approval_mode = "prompt"
tool_timeout_sec = 120

Cursor

Settings → Tools & MCP → Streamable HTTP

url:    https://mcp.signaldig.com/mcp
header: Authorization: Bearer <SIGNALDIG_API_KEY>

Windsurf

macOS/Linux: ~/.codeium/mcp_config.json · Windows: %USERPROFILE%\.codeium\mcp_config.json

{
  "mcpServers": {
    "signaldig": {
      "serverUrl": "https://mcp.signaldig.com/mcp",
      "headers": {
        "Authorization": "Bearer ${env:SIGNALDIG_API_KEY}"
      }
    }
  }
}

VS Code / GitHub Copilot

.vscode/mcp.json

{
  "inputs": [
    {
      "type": "promptString",
      "id": "signaldig-api-key",
      "description": "SignalDig API Key",
      "password": true
    }
  ],
  "servers": {
    "signaldig": {
      "type": "http",
      "url": "https://mcp.signaldig.com/mcp",
      "headers": {
        "Authorization": "Bearer ${input:signaldig-api-key}"
      }
    }
  }
}

Windows: set SIGNALDIG_API_KEY first

  1. Press the Windows key, search for, and open “Edit environment variables for your account.”
  2. Under User variables, click New. Name: SIGNALDIG_API_KEY. Value: your SignalDig API key.
  3. OK to save. Fully quit and reopen your AI client. %USERPROFILE% is your Windows user folder.

Download the release archive, unzip it, and copy research-growth-signals into your agent's skills folder.

Step 1: Download the skills

Download seo-signal-skills.zip ↓

Step 2: Unzip the downloaded file

1

Open your Downloads folder and find the seo-signal-skills-*.zip file.

2

Windows: right-click the file → choose "Extract All…" → click Extract. Mac: just double-click the file — it unzips automatically.

3

A new folder with the release version in its name appears. Open it.

4

Inside you will see one folder: research-growth-signals. It is the only supported Skill.

Step 3: Put the skills into your AI agent

Every AI client (Claude Code, Codex, Cursor, Windsurf…) has its own skills folder. Copy the research-growth-signals folder there.

Can't find the skills folder? Do this:
1

Open your home folder. Mac: press Cmd + Shift + H in Finder. Windows: open File Explorer and go to C:\Users\YourUserName.

2

The skills folder is hidden (its name starts with a dot). To see hidden files: Mac — press Cmd + Shift + .; Windows — click View at the top, then tick Hidden items.

3

Look for the folder named after your AI client: .claude, .codex, .cursor or .windsurf. Open it, then open the skills sub-folder inside.

4

No skills folder? Right-click → New Folder → name it exactly skills.

Step 4: Connect the data service (required)

The skills fetch real data through SignalDig's data service (called MCP). Without this step the AI cannot get real data — so this step cannot be skipped.

MCP is like a bridge between your AI and SignalDig's data service. Here is the easiest way to set it up:

1

Open research-growth-signals/SKILL.md with a text editor.

2

Copy the whole content of SKILL.md, paste it into your AI chat, and tell it: "Please configure this MCP connection for me."

3

The AI will guide you or configure it directly. If it asks for an API Key, click the button below to get a free one.

Get your API key from your SignalDig workspace dashboard. Get your API Key →
